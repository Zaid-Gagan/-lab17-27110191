# Pennywise – Personal Finance & Budget Planner

Take control of your money.

Pennywise is a responsive personal finance application designed to help users manage income, expenses, budgets and savings goals.

## Features

- Financial dashboard with income, expenses and savings summaries
- Transaction management
- Monthly and category-based budget planning
- Spending analytics and visualisations
- Savings goals and progress tracking
- Persistent browser storage using localStorage
- Responsive desktop and mobile layouts

## Technology

- React
- Vite
- JavaScript
- CSS
- LocalStorage

## Run locally

Install dependencies:

npm install

Start the development server:

npm start

Build for production:

npm run build
